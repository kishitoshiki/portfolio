# ポートフォリオサイト

## 概要

WordPressのオリジナルテーマをフルスクラッチで制作したポートフォリオサイトです。

HTML/CSS/JavaScript・PHPを用いてテーマを一から実装し、デザインからコーディング、WordPressへの組み込みまで一貫して担当しました。

---

## ポートフォリオサイト

https://kishitoshiki.com/

---

## 使用技術

- WordPress
- PHP
- HTML5
- CSS3
- JavaScript
- jQuery

---

## 担当範囲

- サイト設計
- デザイン
- HTML/CSSコーディング
- JavaScript実装
- WordPressテーマ制作
- レスポンシブ対応

---

## 主な実装内容

- WordPressオリジナルテーマの作成
- ヘッダー・フッターのテンプレート化
- 投稿ページ・固定ページの実装
- CSSによるレスポンシブデザイン
- JavaScriptを用いた画面演出
- お問い合わせページの作成

## 工夫した点

- WordPressテーマをゼロから設計・実装しました。
- 共通パーツをテンプレート化し、保守性を意識した構成としています。
- レスポンシブデザインに対応し、PC・スマートフォン双方で閲覧しやすいレイアウトを実現しました。
- HTML/CSSだけでなくPHPを利用し、WordPressのテンプレート構造を理解しながら開発を行いました。
